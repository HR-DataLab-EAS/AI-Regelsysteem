# Inleveren

## Inleveren van je project

Na het afronden van je project lever je je werk in via de volgende stappen:

### Stap 1: Bestanden versturen naar projectbegeleider

Stuur de volledige bestanden van je projectgroep in één zip-bestand naar je projectbegeleider via e-mail of een gedeelde opslaglocatie. Zorg ervoor dat je de onderstaande mapstructuur aanhoudt:

```
Groep_[Jouw_Groep]/
├── Bijlage_01_[Naam_van_bijlage]/
│   └── [Jouw bestanden en mappen]
├── Bijlage_02_[Naam_van_bijlage]/
│   └── [Jouw bestanden en mappen]
├── ...
└── Projectdocument_[Naam].pdf
```

### Stap 2: Bijdragen toevoegen aan GitHub repository

Update de hoofd GitHub repository met jouw bijdragen door het volgende proces te volgen:

1. **Fork** de repository naar je eigen GitHub account
2. **Clone** de geforkte repository naar je lokale machine
3. **Maak een nieuwe branch** aan voor jouw projectgroep (bijvoorbeeld: `groep_[Jouw_Groep]`)
4. **Voeg je bestanden toe** aan de juiste map in de `docs/` directory volgens de structuur hieronder
5. **Commit en push** je wijzigingen naar je geforkte repository
6. **Maak een pull request** aan naar de hoofdrepository

**Hulp nodig?** Bekijk deze video tutorial over het forken en pull request proces: [GitHub Fork & Pull Request Tutorial](https://www.youtube.com/watch?v=a_FLqX3vGR4)

### Vereiste mapstructuur in de repository

Zorg dat je bestanden de volgende structuur volgen:

```
docs/
└── Groep_[Jouw_Groep]/
   ├── Onderzoek_01_[Naam_van_onderzoek].pdf
   ├── Onderzoek_02_[Naam_van_onderzoek].pdf
   ├── ...
   └── Projectdocument_[Naam].pdf
```

### Belangrijke aandachtspunten

- Plaats je bestanden in de correcte map: `docs/Groep_[Jouw_Groep]/`
- Houd je aan de voorgeschreven mapstructuur
- Converteer je projectdocument naar PDF-formaat en benoem het als `Projectdocument_[Naam].pdf`
- Voeg alleen relevante onderzoeken en projectdocumenten toe in PDF-formaat
- Gebruik duidelijke en beschrijvende namen voor je bestanden

### Stap 3: Projectdocument markdown invullen

Gebruik de template markdown file om je projectgegevens te documenteren:

1. Navigeer naar de `docs/` directory in de repository
2. Kopieer het bestand `Project_Template.md`
3. Hernoem de kopie naar `Groep_[Jouw_Groep]/Projectdocument_[Naam].md`
